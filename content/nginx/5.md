# Nginx 局域网自签名证书

## 配置步骤

### 1. 生成客户端公钥私钥

自签名证书并配置nginx, 生成客户端公钥私钥

```bash
mkdir new_cert
cd new_cert/
openssl genrsa -out server.key 1024
openssl rsa -in server.key -pubout -out server.pem
openssl genrsa -out client.key 1024
openssl rsa  -in client.key -pubout -out client.pem
```

### 2. 生成 CA 证书

```bash
openssl genrsa -out ca.key 1024
openssl req -new -key ca.key -out ca.csr
openssl x509 -req -in ca.csr -signkey ca.key -out ca.crt
```

### 3. 生成服务器端和客户端 CRT 证书

**注意：** 这里服务端和客户端的 Organization Name (eg, company) 以及 Organizational Unit Name 都必须要和 CA 的不一样才可以

```bash
openssl req -new -key server.key -out server.csr
openssl req -new -key client.key -out client.csr 
openssl x509 -req -CA ca.crt -CAkey ca.key -CAcreateserial -in server.csr -out server.crt
openssl x509 -req -CA ca.crt -CAkey ca.key -CAcreateserial -in client.csr -out client.crt
```

### 4. 生成最终需要的 key 和 crt 文件

```bash
openssl rsa -in server.key -out server_nginx.key
openssl x509 -req -days 3650 -in server.csr -signkey server_nginx.key -out server_nginx.crt
```
