# Nginx 编译安装及标识修改

## 安装准备

### 1. 下载 Nginx 包
去 nginx官网下载 nginx 包，建议下载稳定版本

### 2. 上传到服务器
上传 nginx 到 linux 系统自定义的目录下。（上传工具可以使用 xftp）

### 3. 安装依赖环境
```bash
yum install gcc-c++
yum install -y pcre pcre-devel
yum install -y zlib zlib-devel
yum install -y openssl openssl-devel
```

## 安装配置

### 4. 解压压缩包
解压后得到源码，之后需要编译后安装
```bash
tar -zxvf nginx-1.xx.tar.gz
```

### 5. 创建临时目录
```bash
mkdir /var/temp/nginx -p
```

## 隐藏标识

### 6. 隐藏 Nginx 标识 - 修改源码
```bash
# vim src/core/nginx.h +14
#define NGINX_VER          "wjoyxt/" NGINX_VERSION
# vim src/http/ngx_http_special_response.c  +22 +29 和 +36  （注意修改后无引号，NGINX_VER为变量）
"<hr><center>wjoyxt</center>" CRLF
# vim src/http/ngx_http_header_filter_module.c +49
static char ngx_http_server_string[] = "Server: wjoyxt" CRLF;
```

### 7. 隐藏版本号
curl Nginx服务器时，有这么一行Server: nginx，说明我用的是 Nginx 服务器，但并没有具体的版本号。由于某些 Nginx 漏洞只存在于特定的版本，隐藏版本号可以提高安全性。这只需要在nginx.conf配置里加上这个就可以了：

```
server_tokens off;
```

## 编译安装

### 8. 配置编译选项
切换到 nginx 目录，输入如下命令进行配置
```bash
./configure \
--prefix=/usr/local/nginx \
--pid-path=/var/run/nginx/nginx.pid \
--lock-path=/var/lock/nginx.lock \
--error-log-path=/var/log/nginx/error.log \
--http-log-path=/var/log/nginx/access.log \
--with-http_gzip_static_module \
--http-client-body-temp-path=/var/temp/nginx/client \
--http-proxy-temp-path=/var/temp/nginx/proxy \
--http-fastcgi-temp-path=/var/temp/nginx/fastcgi \
--http-uwsgi-temp-path=/var/temp/nginx/uwsgi \
--http-scgi-temp-path=/var/temp/nginx/scgi
```

### 9. 编译安装
```bash
make && make install
```

### 10. 启动 Nginx
进入 nginx 目录下的 sbin 目录，执行命令
```bash
./nginx
```

### 11. 验证安装
执行./nginx 命令启动后，打开浏览器，访问虚拟机所处内网 ip 即可打开 nginx 默认页面，表示安装成功（默认访问 80 端口，所以保证 80 端口是开启的，如在本地虚拟机，需要关闭防火墙）
