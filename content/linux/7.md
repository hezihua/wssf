# FNM 离线安装

## 安装步骤

### 1. FNM 离线安装命令

```bash
mkdir -p ~/.fnm && \
curl -L https://github.com/Schniz/fnm/releases/latest/download/fnm-linux.zip -o /tmp/fnm.zip && \
unzip /tmp/fnm.zip -d /tmp && \
mv /tmp/fnm ~/.fnm/fnm && \
chmod +x ~/.fnm/fnm && \
echo 'export PATH="$HOME/.fnm:$PATH"' >> ~/.bashrc && \
echo 'eval "$(fnm env)"' >> ~/.bashrc && \
source ~/.bashrc && \
fnm --version
```
