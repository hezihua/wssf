# PS 进程管理命令

## 常用命令

### 1. ps aux

列出系统中所有用户的所有进程。

输出包括用户、PID、CPU 和内存使用率、进程运行时间、进程命令等。

**参数说明：**
- `a`: 显示所有用户的进程
- `u`: 以用户友好的格式显示输出（包括用户名和更详细的信息）
- `x`: 显示没有控制终端的进程（包括后台进程）

### 2. ps -ef

列出所有进程

### 3. ps -u [username]

查看特定用户的进程

### 4. ps -p [PID]

显示指定进程 ID（PID）的详细信息。

### 5. ps --forest

显示进程之间的父子关系，帮助查看进程的继承结构。

可以与 -f 或 aux 结合使用。

```
ps -ef --forest
```

### 6. ps -C [command]

ps -C nginx

### 7. ps -T -p [PID]

查看某个进程的所有线程。

### 8. ps aux --sort=-%cpu / ps aux --sort=-%mem

按 CPU 或内存使用率排序显示进程。

--sort=-%cpu: 按 CPU 使用率降序排列。

--sort=-%mem: 按内存使用率降序排列。

### 9. ps -eo pid,lstart,cmd | grep [PID]

显示进程的启动时间及启动的命令。

### 10. ps e -p [PID]

显示指定进程的环境变量。
