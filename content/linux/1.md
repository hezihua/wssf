# Linux 常用命令

在 Linux 系统中，端口管理和网络相关的命令。

## 网络相关命令

### 1. netstat

netstat 用于显示网络连接、路由表、接口统计、伪装连接和多播成员资格。
```
常见用法：

netstat -tuln

显示所有正在监听的 TCP 和 UDP 端口及其状态。

```


### 2. ss

ss 是 netstat 的现代替代品，用于显示套接字统计信息。

```
常见用法：

ss -tuln

显示所有正在监听的 TCP 和 UDP 端口及其状态。
```

### 3. lsof

lsof（list open files）显示系统中打开的文件和网络端口。

```
常见用法：

lsof -i :80

显示与端口 80 相关的所有打开文件和进程信息。
```




### 4. nmap

nmap（Network Mapper）是一个网络扫描和端口扫描工具，用于发现网络上的设备和开放的端口。

```
常见用法：

nmap -p 80 localhost

扫描本地主机上的端口 80 是否开放。
```

### 5. nc（netcat）

nc 是一个用于读写网络连接的工具。

```
常见用法：

nc -l 12345

在端口 12345 上监听。

echo "Hello" | nc localhost 12345

向本地主机的端口 12345 发送 "Hello"。
```


### 6. telnet

telnet 用于与远程主机建立 TCP 连接，通常用于调试和测试目的。

```
常见用法：

telnet localhost 80

尝试连接本地主机的端口 80。
```


### 7. curl

curl 是一个用于传输数据的命令行工具，可以与 HTTP/HTTPS 端口进行交互。


```
常见用法：

curl http://localhost:80

访问本地主机的端口 80 上的 HTTP 服务。
```
