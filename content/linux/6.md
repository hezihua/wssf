# PM2 进程管理工具

## 常用命令

### 1. PM2 基础命令

```bash
# 启动服务（使用配置文件）
pm2 start ecosystem.config.js

# 启动服务（使用 npm 脚本）
pm2 start npm --name "nextjs-app" -- run start:test 

# 查看进程列表
pm2 list

# 查看日志
pm2 logs

# 重启应用
pm2 restart your-app-name

# 停止应用
pm2 stop your-app-name

# 删除应用
pm2 delete your-app-name
```
