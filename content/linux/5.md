# Linux 软件包管理

## 软件包管理工具

### 1. RPM 包管理

```bash
rpm -ivh package_name.rpm  # 安装软件包

rpm -Uvh package_name.rpm  # 升级软件包

rpm -e package_name # 卸载软件包

rpm -qa | grep package_name # 查询已安装的软件包

rpm -qi package_name # 查看软件包信息

rpm -V package_name # 验证软件包
```

### 2. YUM 包管理

```bash
sudo yum install package_name  # 安装软件包

sudo yum update package_name  # 升级软件包

sudo yum remove package_name # 卸载软件包

yum list available # 查看可用的软件包

yum list installed # 查询已安装的软件包

yum search keyword # 查找特定的软件包

yum info package_name # 显示软件包信息

sudo yum clean all # 清除缓存

yum check-update # 列出可用的更新

sudo yum groupinstall "Development Tools" # 安装软件包组
```
