# Systemd 服务管理

## 基础介绍

### 1. Systemd 命令介绍

在 `/etc/systemd/system/` 目录下创建文件

### 2. 核心组件

- **systemctl**：这是 systemd 的核心命令行工具，用于启动、停止、重启服务，查看状态等
- **journalctl**：用于查看和管理由 systemd-journald 收集的系统日志
- **systemd-analyze**：用于分析系统启动时间，帮助优化系统启动速度
- **timedatectl**：用于查看和设置系统的时间和时区
- **loginctl**：用于管理用户登录会话

### 3. 重要命令

```bash
sudo systemctl daemon-reload  # 加载文件
```

## 配置示例

### 4. Nginx 服务配置
```
[Unit]
Description=NGINX service
After=network.target

[Service]
Type=forking
ExecStart=/usr/bin/nginx
ExecReload=/bin/kill -s HUP $MAINPID
ExecStop=/bin/kill -s TERM $MAINPID
PIDFile=/var/run/nginx/nginx.pid
User=root
Group=root

[Install]
WantedBy=multi-user.target
```

```
sudo systemctl start nginx

sudo systemctl stop nginx

sudo systemctl status nginx

sudo systemctl enable nginx

开机自启
```
