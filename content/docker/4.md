# Docker 镜像源配置

## 配置步骤

### 1. 创建或修改配置文件

创建或修改 docker的镜像源文件 daemon.json 

```
cd /etc/docker

vim daemon.json

{
  "registry-mirrors": [
    "https://docker.m.daocloud.io",
    "https://registry.docker-cn.com",
    "https://quay.mirrors.ustc.edu.cn",
    "https://hub-mirror.c.163.com/",
    "https://dockerhub.icu"
  ]
}
```

1.重启docker 

```
systemctl daemon-reload
systemctl restart docker

```
