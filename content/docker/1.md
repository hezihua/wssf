# 镜像

```
docker search 镜像名称  -- 查找镜像

docker pull 镜像名称:标签（版本号） --拉取镜像

docker images -- 查找本地镜像

docker rmi 镜像名称:版本号  --删除镜像
```

# 容器

```
docker run 参数... 镜像名称  -- 创建并运行容器

docker ps -a  --查看容器

docker rm 容器id或名称  --删除容器

docker stop 容器id或名称  --停止容器

docker start 容器id或名称  --启动容器

docker logs 容器id或名称  --查看容器日志

docker exec -it    容器id或名称    进入后执行的命令   --进入容器
```
