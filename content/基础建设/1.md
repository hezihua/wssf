# Verdaccio 搭建私有仓库

## 安装步骤

### 1. 拉取镜像

```
docker pull verdaccio/verdaccio
```

### 2. 构建volume
```
docker volume create verdaccio
```

### 3. 启动容器
```
docker run -d --name verdaccio -p 4873:4873 -v verdaccio:/verdaccio verdaccio/verdaccio
```

### 4. 访问
```
http://127.0.0.1:4873/
```
