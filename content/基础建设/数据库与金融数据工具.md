## Flyway - 数据库迁移管理工具

### 🔖 简介

Flyway是一个开源的数据库迁移管理工具，帮助开发者以版本化的方式管理数据库schema变更。它支持多种数据库系统，包括MySQL、PostgreSQL、Oracle、SQL Server等。

### 🎯 核心特性

- **版本化迁移**：每个迁移脚本都有唯一的版本号
- **自动执行**：按顺序自动执行未运行的迁移脚本
- **回滚支持**：支持数据库schema回滚
- **多环境支持**：开发、测试、生产环境统一管理
- **团队协作**：避免schema变更冲突

#### 2. Python中执行迁移

```python
# migration_manager.py
from flyway import Flyway
import logging

class DatabaseMigrationManager:
    def __init__(self, database_url, username, password):
        self.flyway = Flyway(
            url=database_url,
            user=username,
            password=password,
            locations=["filesystem:./migrations"]
        )
    
    def get_migration_info(self):
        """获取迁移状态信息"""
        return self.flyway.info()
    
    def migrate(self):
        """执行数据库迁移"""
        try:
            result = self.flyway.migrate()
            logging.info(f"迁移完成，执行了 {result.migrations_executed} 个迁移")
            return result
        except Exception as e:
            logging.error(f"迁移失败: {e}")
            raise
    
    def validate(self):
        """验证迁移"""
        return self.flyway.validate()

# 使用示例
if __name__ == "__main__":
    manager = DatabaseMigrationManager(
        database_url="postgresql://localhost:5432/myapp",
        username="postgres",
        password="password"
    )
    
    # 查看迁移状态
    info = manager.get_migration_info()
    print(info)
    
    # 执行迁移
    manager.migrate()
```

### 🎨 最佳实践

- 迁移脚本命名规范：`V{版本号}__{描述}.sql`
- 永远不要修改已执行的迁移脚本
- 使用事务确保迁移原子性
- 在生产环境前先在测试环境验证

## Bytebase - 数据库DevOps平台

### 🔖 简介

Bytebase是一个现代化的数据库DevOps平台，提供数据库schema变更管理、SQL审核、数据安全和团队协作功能。它为数据库管理带来了GitLab式的工作流程。

### 🎯 核心特性

- **可视化Schema变更**：通过Web界面管理数据库变更
- **SQL审核**：自动化SQL语句安全检查
- **多环境管理**：支持开发/测试/生产环境流水线
- **审批工作流**：数据库变更审批机制
- **数据安全**：敏感数据访问控制和审计

```python
from bytebase import BytebaseClient
```

## OpenFIGI - 金融工具全局标识符

### 🔖 简介

OpenFIGI（Financial Instrument Global Identifier）是由Bloomberg开发的免费金融工具标识符服务。它为各种金融工具提供唯一的全球标识符，促进金融数据的标准化和互操作性。

### 🎯 核心特性

- **全球标准**：ISO 25962标准化的金融工具标识符
- **多类型支持**：股票、债券、期权、期货、基金等
- **免费API**：提供RESTful API接口
- **高覆盖率**：支持全球主要交易所的金融工具
- **实时更新**：标识符数据实时维护更新

#### Python SDK完整示例

```python
import requests
import json

class OpenFIGIClient:
    def __init__(self, api_key=None):
        self.base_url = "https://api.openfigi.com"
        self.api_key = api_key
        self.headers = {
            'Content-Type': 'application/json'
        }
        if api_key:
            self.headers['X-OPENFIGI-APIKEY'] = api_key
    
    def search_figi(self, identifier_type, identifier_value, 
                   exchange_code=None, mic_code=None):
        """搜索FIGI标识符"""
        endpoint = f"{self.base_url}/v3/search"
        
        payload = [{
            "idType": identifier_type,
            "idValue": identifier_value
        }]
        
        if exchange_code:
            payload[0]["exchCode"] = exchange_code
        if mic_code:
            payload[0]["micCode"] = mic_code
            
        response = requests.post(
            endpoint, 
            headers=self.headers,
            data=json.dumps(payload)
        )
        
        return response.json()
    
    def get_mapping(self, figi):
        """获取FIGI映射信息"""
        endpoint = f"{self.base_url}/v3/mapping"
        
        payload = [{"idType": "ID_FIGI", "idValue": figi}]
        
        response = requests.post(
            endpoint,
            headers=self.headers, 
            data=json.dumps(payload)
        )
        
        return response.json()

# 使用示例
client = OpenFIGIClient(api_key="your_api_key")

# 搜索Apple股票的FIGI
result = client.search_figi(
    identifier_type="ID_ISIN",
    identifier_value="US0378331005",  # Apple ISIN
    mic_code="XNAS"  # NASDAQ
)

print(json.dumps(result, indent=2))
```

#### 2. Mapping功能详解

Mapping功能用于将FIGI标识符映射到其他标识符类型，实现不同标识符系统之间的转换。

```python
# figi_mapping.py
class FIGIMappingManager:
    def __init__(self, client):
        self.client = client
    
    def get_figi_mapping(self, figi, target_types=None):
        """获取FIGI的映射信息"""
        if target_types is None:
            target_types = ["TICKER", "ISIN", "CUSIP", "SEDOL", "RIC"]
        
        mapping_request = [{
            "idType": "ID_FIGI", 
            "idValue": figi
        }]
        
        response = self.client.get_mapping(mapping_request)
        
        if response and len(response) > 0 and 'data' in response[0]:
            mappings = {}
            for data_item in response[0]['data']:
                for target_type in target_types:
                    key = target_type.lower()
                    if key in data_item:
                        mappings[target_type] = data_item[key]
            
            return mappings
        
        return {}
    
    def bulk_mapping(self, figis, target_types=None):
        """批量获取FIGI映射"""
        results = {}
        
        for figi in figis:
            try:
                mapping = self.get_figi_mapping(figi, target_types)
                results[figi] = mapping
                time.sleep(0.1)  # API限制
            except Exception as e:
                print(f"FIGI {figi} 映射失败: {e}")
                results[figi] = {}
        
        return results

# 使用示例
mapper = FIGIMappingManager(client)

# 单个FIGI映射
figi = "BBG000B9XRY4"  # Apple的FIGI
mapping = mapper.get_figi_mapping(figi)
print(f"FIGI {figi} 映射结果:")
for id_type, value in mapping.items():
    print(f"  {id_type}: {value}")

# 批量映射
figis = ["BBG000B9XRY4", "BBG000BPH459", "BBG009S39JX6"]
bulk_mappings = mapper.bulk_mapping(figis)

# 转换为DataFrame
mapping_df = pd.DataFrame.from_dict(bulk_mappings, orient='index')
print(mapping_df)
```

#### 3. Filter功能详解

Filter功能允许您根据各种条件过滤搜索结果，提高查询精度。

```python
# figi_filter.py
class FIGIFilterManager:
    def __init__(self, client):
        self.client = client
        
    def search_with_filters(self, identifier_type, identifier_value, filters=None):
        """使用过滤器搜索FIGI"""
        if filters is None:
            filters = {}
        
        search_request = [{
            "idType": identifier_type,
            "idValue": identifier_value
        }]
        
        # 添加过滤器
        if "exchCode" in filters:
            search_request[0]["exchCode"] = filters["exchCode"]
        if "micCode" in filters:
            search_request[0]["micCode"] = filters["micCode"]
        if "currency" in filters:
            search_request[0]["currency"] = filters["currency"]
        if "marketSecDes" in filters:
            search_request[0]["marketSecDes"] = filters["marketSecDes"]
        if "securityType" in filters:
            search_request[0]["securityType"] = filters["securityType"]
        if "securityType2" in filters:
            search_request[0]["securityType2"] = filters["securityType2"]
        if "includeUnlistedEquities" in filters:
            search_request[0]["includeUnlistedEquities"] = filters["includeUnlistedEquities"]
        
        response = self.client.search_figi(search_request)
        return self._process_filtered_results(response, filters)
    
    def _process_filtered_results(self, response, applied_filters):
        """处理过滤后的结果"""
        processed_results = []
        
        if response and len(response) > 0 and 'data' in response[0]:
            for item in response[0]['data']:
                # 应用额外的后处理过滤器
                if self._passes_additional_filters(item, applied_filters):
                    processed_results.append({
                        'figi': item.get('figi'),
                        'security_type': item.get('securityType'),
                        'security_type2': item.get('securityType2'),
                        'market_sector': item.get('marketSector'),
                        'ticker': item.get('ticker'),
                        'name': item.get('name'),
                        'exchange_code': item.get('exchCode'),
                        'mic_code': item.get('micCode'),
                        'currency': item.get('currency'),
                        'composite_figi': item.get('compositeFIGI'),
                        'share_class_figi': item.get('shareClassFIGI'),
                        'unique_id': item.get('uniqueID')
                    })
        
        return processed_results
    
    def _passes_additional_filters(self, item, filters):
        """检查项目是否通过额外过滤器"""
        # 可以在这里添加更复杂的过滤逻辑
        if "min_market_value" in filters:
            # 示例：根据市场价值过滤
            pass
        
        return True
    
    def filter_by_security_type(self, ticker, allowed_types):
        """根据证券类型过滤"""
        all_results = self.client.search_figi(
            identifier_type="TICKER",
            identifier_value=ticker
        )
        
        filtered_results = []
        for result in all_results:
            if result and 'data' in result:
                for item in result['data']:
                    if item.get('securityType') in allowed_types:
                        filtered_results.append(item)
        
        return filtered_results

# 高级过滤示例
filter_manager = FIGIFilterManager(client)

# 1. 按交易所过滤
nasdaq_apple = filter_manager.search_with_filters(
```

#### 4. 批量查询与数据处理

```python
# batch_figi_processor.py
import pandas as pd
from concurrent.futures import ThreadPoolExecutor
import time

class FIGIBatchProcessor:
    def __init__(self, client):
        self.client = client
        self.mapper = FIGIMappingManager(client)
        self.filter_manager = FIGIFilterManager(client)
    
    def process_batch_with_mapping_and_filters(self, symbols_data, 
                                             mapping_types=None, 
                                             common_filters=None,
                                             batch_size=50):
        """批量处理，包含映射和过滤"""
        if mapping_types is None:
            mapping_types = ["TICKER", "ISIN", "CUSIP"]
        
        if common_filters is None:
            common_filters = {}
        
        results = []
        
        for i in range(0, len(symbols_data), batch_size):
            batch = symbols_data[i:i + batch_size]
            
            try:
                # 1. 搜索FIGI
                search_results = []
                for symbol_data in batch:
                    # 应用过滤器
                    symbol_filters = {**common_filters, **symbol_data.get('filters', {})}
                    
                    filtered_result = self.filter_manager.search_with_filters(
                        identifier_type=symbol_data['idType'],
                        identifier_value=symbol_data['idValue'], 
                        filters=symbol_filters
                    )
                    search_results.extend(filtered_result)
                
                # 2. 获取映射
                for result in search_results:
                    if result.get('figi'):
                        mappings = self.mapper.get_figi_mapping(
                            result['figi'], 
                            mapping_types
                        )
                        result.update(mappings)
                
                results.extend(search_results)
                
                # API限制延迟
                time.sleep(1)
                
            except Exception as e:
                print(f"批次 {i//batch_size + 1} 处理失败: {e}")
                continue
        
        return results
    
    def create_comprehensive_dataframe(self, results):
        """创建包含所有信息的综合DataFrame"""
        df_data = []
        
        for result in results:
            row = {
                # 基本FIGI信息
                'figi': result.get('figi'),
                'composite_figi': result.get('composite_figi'),
                'share_class_figi': result.get('share_class_figi'),
                
                # 证券信息
                'name': result.get('name'),
                'ticker': result.get('ticker'),
                'security_type': result.get('security_type'),
                'security_type2': result.get('security_type2'),
                'market_sector': result.get('market_sector'),
                
                # 交易所信息
                'exchange_code': result.get('exchange_code'),
                'mic_code': result.get('mic_code'),
                'currency': result.get('currency'),
                
                # 映射标识符
                'isin': result.get('ISIN'),
                'cusip': result.get('CUSIP'),
                'sedol': result.get('SEDOL'),
                'ric': result.get('RIC'),
                
                # 其他信息
                'unique_id': result.get('unique_id')
            }
            df_data.append(row)
        
        return pd.DataFrame(df_data)

# 综合使用示例
processor = FIGIBatchProcessor(client)

# 定义要查询的符号及其特定过滤器
symbols_with_filters = [
    {
        "idType": "TICKER",

        "filters": {"exchCode": "US"}
    }
]

# 公共过滤器
common_filters = {
    "currency": "USD",
    "securityType": "Common Stock"
}

# 执行综合处理
comprehensive_results = processor.process_batch_with_mapping_and_filters(
    symbols_data=symbols_with_filters,
    mapping_types=["TICKER", "ISIN", "CUSIP", "SEDOL"],
    common_filters=common_filters

# 创建综合DataFrame

# 显示结果
print("综合查询结果:")
print(comprehensive_df.to_string())

# 保存到Excel，包含多个工作表
with pd.ExcelWriter('comprehensive_figi_data.xlsx') as writer:
    comprehensive_df.to_excel(writer, sheet_name='Complete_Data', index=False)
    
    # 按证券类型分组
```

```python
# advanced_figi_applications.py
class AdvancedFIGIApplications:
    def __init__(self, client):
        self.client = client
        self.processor = FIGIBatchProcessor(client)
    
    def build_market_universe(self, tickers, market_filters):
        """构建特定市场的证券池"""
        market_universe = {}
        
        for market_name, filters in market_filters.items():
            print(f"构建 {market_name} 证券池...")
            
            market_securities = []
            for ticker in tickers:
                try:
                    results = self.processor.filter_manager.search_with_filters(
                        identifier_type="TICKER",
                        identifier_value=ticker,
                        filters=filters
                    )
                    market_securities.extend(results)
                except Exception as e:
                    print(f"处理 {ticker} 时出错: {e}")
            
            market_universe[market_name] = pd.DataFrame(market_securities)
        
        return market_universe
    
    def cross_listing_analysis(self, tickers):
        """分析跨市场上市情况"""
        cross_listings = {}
        
        for ticker in tickers:
            # 搜索所有市场的相同ticker
            all_listings = self.client.search_figi(
                identifier_type="TICKER", 
                identifier_value=ticker
            )
            
            if all_listings and len(all_listings) > 0 and 'data' in all_listings[0]:
                listings_data = []
                for item in all_listings[0]['data']:
                    listings_data.append({
                        'ticker': ticker,
                        'figi': item.get('figi'),
                        'exchange': item.get('exchCode'),
                        'mic_code': item.get('micCode'),
                        'currency': item.get('currency'),
                        'name': item.get('name'),
                        'security_type': item.get('securityType')
                    })
                
                cross_listings[ticker] = pd.DataFrame(listings_data)
        
        return cross_listings
    
    def identifier_mapping_matrix(self, figis):
        """创建标识符映射矩阵"""
        mapping_matrix = []
        
        for figi in figis:
            mappings = self.processor.mapper.get_figi_mapping(
                figi, 
                target_types=["TICKER", "ISIN", "CUSIP", "SEDOL", "RIC"]
            )
            
            row = {"FIGI": figi}
            row.update(mappings)
            mapping_matrix.append(row)
        
        return pd.DataFrame(mapping_matrix)
    
    def validate_identifiers(self, identifier_pairs):
        """验证标识符对应关系"""
        validation_results = []
        
        for pair in identifier_pairs:
            id_type1, id_value1 = pair['primary']['type'], pair['primary']['value']
            id_type2, id_value2 = pair['secondary']['type'], pair['secondary']['value']
            
            # 通过第一个标识符查找FIGI
            result1 = self.client.search_figi(
                identifier_type=id_type1,
                identifier_value=id_value1
            )
            
            # 通过第二个标识符查找FIGI
            result2 = self.client.search_figi(
                identifier_type=id_type2, 
                identifier_value=id_value2
            )
            
            # 比较FIGI是否匹配
            figis1 = set()
            figis2 = set()
            
            if result1 and len(result1) > 0 and 'data' in result1[0]:
                figis1 = {item.get('figi') for item in result1[0]['data']}
            
            if result2 and len(result2) > 0 and 'data' in result2[0]:
                figis2 = {item.get('figi') for item in result2[0]['data']}
            
            validation_results.append({
                'primary_id': f"{id_type1}:{id_value1}",
                'secondary_id': f"{id_type2}:{id_value2}",
                'figis_match': bool(figis1.intersection(figis2)),
                'primary_figis': list(figis1),
                'secondary_figis': list(figis2),
                'common_figis': list(figis1.intersection(figis2))
            })
        
        return pd.DataFrame(validation_results)
```
