15:T1b7c,<h1>Nginx 编译安装及标识修改</h1>
<h2>安装准备</h2>
<h3>1. 下载 Nginx 包</h3>
<p>去 nginx官网下载 nginx 包，建议下载稳定版本</p>
<h3>2. 上传到服务器</h3>
<p>上传 nginx 到 linux 系统自定义的目录下。（上传工具可以使用 xftp）</p>
<h3>3. 安装依赖环境</h3>
<figure data-rehype-pretty-code-figure=""><pre tabindex="0" data-language="bash" data-theme="github-dark-dimmed"><code data-language="bash" data-theme="github-dark-dimmed" style="display: grid;"><span data-line=""><span style="color:#F69D50">yum</span><span style="color:#96D0FF"> install</span><span style="color:#96D0FF"> gcc-c++</span></span>
<span data-line=""><span style="color:#F69D50">yum</span><span style="color:#96D0FF"> install</span><span style="color:#6CB6FF"> -y</span><span style="color:#96D0FF"> pcre</span><span style="color:#96D0FF"> pcre-devel</span></span>
<span data-line=""><span style="color:#F69D50">yum</span><span style="color:#96D0FF"> install</span><span style="color:#6CB6FF"> -y</span><span style="color:#96D0FF"> zlib</span><span style="color:#96D0FF"> zlib-devel</span></span>
<span data-line=""><span style="color:#F69D50">yum</span><span style="color:#96D0FF"> install</span><span style="color:#6CB6FF"> -y</span><span style="color:#96D0FF"> openssl</span><span style="color:#96D0FF"> openssl-devel</span></span></code></pre></figure>
<h2>安装配置</h2>
<h3>4. 解压压缩包</h3>
<p>解压后得到源码，之后需要编译后安装</p>
<figure data-rehype-pretty-code-figure=""><pre tabindex="0" data-language="bash" data-theme="github-dark-dimmed"><code data-language="bash" data-theme="github-dark-dimmed" style="display: grid;"><span data-line=""><span style="color:#F69D50">tar</span><span style="color:#6CB6FF"> -zxvf</span><span style="color:#96D0FF"> nginx-1.xx.tar.gz</span></span></code></pre></figure>
<h3>5. 创建临时目录</h3>
<figure data-rehype-pretty-code-figure=""><pre tabindex="0" data-language="bash" data-theme="github-dark-dimmed"><code data-language="bash" data-theme="github-dark-dimmed" style="display: grid;"><span data-line=""><span style="color:#F69D50">mkdir</span><span style="color:#96D0FF"> /var/temp/nginx</span><span style="color:#6CB6FF"> -p</span></span></code></pre></figure>
<h2>隐藏标识</h2>
<h3>6. 隐藏 Nginx 标识 - 修改源码</h3>
<figure data-rehype-pretty-code-figure=""><pre tabindex="0" data-language="bash" data-theme="github-dark-dimmed"><code data-language="bash" data-theme="github-dark-dimmed" style="display: grid;"><span data-line=""><span style="color:#768390"># vim src/core/nginx.h +14</span></span>
<span data-line=""><span style="color:#768390">#define NGINX_VER          "wjoyxt/" NGINX_VERSION</span></span>
<span data-line=""><span style="color:#768390"># vim src/http/ngx_http_special_response.c  +22 +29 和 +36  （注意修改后无引号，NGINX_VER为变量）</span></span>
<span data-line=""><span style="color:#F69D50">"&#x3C;hr>&#x3C;center>wjoyxt&#x3C;/center>"</span><span style="color:#96D0FF"> CRLF</span></span>
<span data-line=""><span style="color:#768390"># vim src/http/ngx_http_header_filter_module.c +49</span></span>
<span data-line=""><span style="color:#F69D50">static</span><span style="color:#96D0FF"> char</span><span style="color:#96D0FF"> ngx_http_server_string[]</span><span style="color:#96D0FF"> =</span><span style="color:#96D0FF"> "Server: wjoyxt"</span><span style="color:#96D0FF"> CRLF</span><span style="color:#ADBAC7">;</span></span></code></pre></figure>
<h3>7. 隐藏版本号</h3>
<p>curl Nginx服务器时，有这么一行Server: nginx，说明我用的是 Nginx 服务器，但并没有具体的版本号。由于某些 Nginx 漏洞只存在于特定的版本，隐藏版本号可以提高安全性。这只需要在nginx.conf配置里加上这个就可以了：</p>
<pre><code>server_tokens off;
</code></pre>
<h2>编译安装</h2>

<span data-line=""><span style="color:#ADBAC7">--prefix=/usr/local/nginx </span><span style="color:#F47067">\</span></span>
<span data-line=""><span style="color:#ADBAC7">--pid-path=/var/run/nginx/nginx.pid </span><span style="color:#F47067">\</span></span>
<span data-line=""><span style="color:#ADBAC7">--lock-path=/var/lock/nginx.lock </span><span style="color:#F47067">\</span></span>
<span data-line=""><span style="color:#ADBAC7">--error-log-path=/var/log/nginx/error.log </span><span style="color:#F47067">\</span></span>
<span data-line=""><span style="color:#ADBAC7">--http-log-path=/var/log/nginx/access.log </span><span style="color:#F47067">\</span></span>
<span data-line=""><span style="color:#ADBAC7">--with-http_gzip_static_module </span><span style="color:#F47067">\</span></span>
<span data-line=""><span style="color:#ADBAC7">--http-client-body-temp-path=/var/temp/nginx/client </span><span style="color:#F47067">\</span></span>
<span data-line=""><span style="color:#ADBAC7">--http-proxy-temp-path=/var/temp/nginx/proxy </span><span style="color:#F47067">\</span></span>
<span data-line=""><span style="color:#ADBAC7">--http-fastcgi-temp-path=/var/temp/nginx/fastcgi </span><span style="color:#F47067">\</span></span>
<span data-line=""><span style="color:#ADBAC7">--http-uwsgi-temp-path=/var/temp/nginx/uwsgi </span><span style="color:#F47067">\</span></span>
<span data-line=""><span style="color:#ADBAC7">--http-scgi-temp-path=/var/temp/nginx/scgi</span></span></code></pre></figure>
<h3>9. 编译安装</h3>
<figure data-rehype-pretty-code-figure=""><pre tabindex="0" data-language="bash" data-theme="github-dark-dimmed"><code data-language="bash" data-theme="github-dark-dimmed" style="display: grid;"><span data-line=""><span style="color:#F69D50">make</span><span style="color:#ADBAC7"> &#x26;&#x26; </span><span style="color:#F69D50">make</span><span style="color:#96D0FF"> install</span></span></code></pre></figure>
<h3>10. 启动 Nginx</h3>
<p>进入 nginx 目录下的 sbin 目录，执行命令</p>
<figure data-rehype-pretty-code-figure=""><pre tabindex="0" data-language="bash" data-theme="github-dark-dimmed"><code data-language="bash" data-theme="github-dark-dimmed" style="display: grid;"><span data-line=""><span style="color:#F69D50">./nginx</span></span></code></pre></figure>
<h3>11. 验证安装</h3>
