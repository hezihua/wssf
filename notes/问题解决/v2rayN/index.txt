15:T2b4e,<h1>v2rayN 下载与使用实践指南</h1>
<blockquote>
<p>本文档适用于 v2rayN V7.x 版本，Windows 平台。</p>
</blockquote>
<h2>一、下载安装</h2>
<h3>1.1 下载 v2rayN</h3>
<p>访问 GitHub Releases 页面下载最新版：</p>
<p>🔗 <a href="https://github.com/2dust/v2rayN/releases">https://github.com/2dust/v2rayN/releases</a></p>
<p>选择带有 <code>windows-64-With-Core</code> 后缀的压缩包，例如：</p>
<pre><code>v2rayN-With-Core.zip
</code></pre>
<p><strong>提示：</strong> With-Core 版本内置了 Xray 核心，下载后可直接使用，无需额外配置。</p>
<h3>1.2 解压运行</h3>
<ol>
<li>将下载的压缩包解压到任意文件夹（建议放在非系统盘，如 <code>D:\v2rayN</code>）</li>
<li>进入解压后的文件夹，双击运行 <code>v2rayN.exe</code></li>
<li>首次运行可能会提示 Windows 安全警告，点击 <strong>「更多信息」 → 「仍要运行」</strong></li>
</ol>
<p><strong>注意：</strong> v2rayN 不需要安装，解压即用。建议右键 <code>v2rayN.exe</code> → <strong>「发送到」 → 「桌面快捷方式」</strong>，方便下次启动。</p>
<h2>二、添加订阅</h2>
<h3>2.1 打开订阅分组设置</h3>
<p>启动 v2rayN 后，点击顶部菜单栏的 <strong>「订阅分组」</strong> → 选择 <strong>「订阅分组设置」</strong>。</p>
<h3>2.2 添加订阅链接</h3>
<p>在弹出的「订阅分组设置」窗口中：</p>
<ol>
<li>点击 <strong>「添加」</strong> 按钮</li>
<li>填写以下信息：
<ul>
<li><strong>别名：</strong> 自定义一个名称，例如 <code>JMS</code></li>
<li><strong>可选地址 (Url)：</strong> 粘贴你的订阅链接</li>
<li><strong>启用更新：</strong> 勾选 ✓</li>
<li><strong>自动更新间隔：</strong> 建议设为 <code>60</code>（分钟），留 <code>0</code> 表示不自动更新</li>
</ul>
</li>
<li>点击 <strong>「确认」</strong> 保存</li>
</ol>
<h3>2.3 关闭设置窗口</h3>
<p>点击右上角的 <strong>「关闭」</strong> 或 × 按钮，回到主界面。</p>
<h2>三、更新订阅获取节点</h2>
<p>回到主界面后，获取服务器节点：</p>
<ol>
<li>点击顶部菜单 <strong>「订阅分组」</strong></li>
<li>选择 <strong>「更新全部订阅（不通过代理）」</strong></li>
<li>或者点击主界面上方工具栏的 🔄 刷新图标</li>
</ol>
<p>等待片刻，主界面中间的列表区域会出现节点信息，包含：</p>
<ul>
<li>类型（Shadowsocks / VLESS / VMess 等）</li>
<li>别名</li>
<li>地址</li>
<li>端口</li>
<li>传输协议</li>
<li>TLS</li>
<li>延迟</li>
</ul>
<h2>四、选择节点</h2>
<p>在节点列表中，<strong>右键点击</strong> 你想使用的节点 → 选择 <strong>「设为活动服务器」</strong>。</p>
<p><strong>建议：</strong> 优先选择 VLESS 类型的节点，相比 Shadowsocks 更安全、更稳定。</p>
<h2>五、开启系统代理</h2>
<h3>5.1 设置代理模式</h3>
<p>看窗口右下角的代理状态按钮：</p>
<ol>
<li>点击当前显示的文字（如 <strong>「清除系统代理」</strong>）</li>
<li>在弹出的菜单中选择 <strong>「自动配置系统代理」</strong></li>
</ol>
<h3>5.2 验证代理是否生效</h3>
<p>打开浏览器，访问以下网站测试：</p>
<ul>
<li><a href="https://www.google.com">https://www.google.com</a></li>
<li><a href="https://www.youtube.com">https://www.youtube.com</a></li>
</ul>
<p>如果能正常打开，说明代理配置成功！</p>
<h2>六、Git 代理配置（命令行工具）</h2>
<p>v2rayN 开启「自动配置系统代理」后，浏览器等应用会自动走代理，但 Git 等命令行工具不会自动跟随系统代理，需要单独配置。</p>

<h2>八、常见问题</h2>
<p><strong>Q1: 更新订阅失败，节点列表为空</strong></p>
<ul>
<li>检查订阅链接是否正确、是否过期</li>
<li>尝试选择「更新全部订阅（通过代理）」</li>
<li>确认网络连接正常</li>
</ul>
<p><strong>Q2: 节点有延迟但打不开网站</strong></p>
<ul>
<li>尝试切换其他节点</li>
<li>检查右下角是否为「自动配置系统代理」</li>
<li>重启 v2rayN 客户端</li>
</ul>
<p><strong>Q3: 提示「配置项无效，请检查或重新选择」</strong></p>
<ul>
<li>说明当前没有选中有效节点</li>
<li>更新订阅后，在列表中右键选择一个节点设为活动服务器</li>
</ul>
<p><strong>Q4: 右下角显示「当前延迟: none」</strong></p>
<ul>
<li>表示该节点无法连通</li>
<li>右键点击节点 →「测试服务器延迟」确认</li>
<li>换一个节点试试</li>
</ul>
<p><strong>Q5: 日志提示 Shadowsocks 已弃用</strong></p>
<ul>
<li>这只是警告，不影响使用</li>
<li>建议优先选择 VLESS 节点以获得更好的安全性和性能</li>
</ul>
<p><strong>Q6: Git 拉取 gitee 代码报错 Failed to connect to 127.0.0.1 port 1080</strong></p>
<ul>
<li>
<p>说明 git 配置了旧的代理端口（如 1080），与 v2rayN 实际端口不一致</p>
</li>
<li>
<p>按 <strong>第六章</strong> 重新配置 git 代理即可</p>
</li>
<li>
<p>或者为 gitee 单独设置直连：</p>
<figure data-rehype-pretty-code-figure=""><pre tabindex="0" data-language="bash" data-theme="github-dark-dimmed"><code data-language="bash" data-theme="github-dark-dimmed" style="display: grid;"><span data-line=""><span style="color:#F69D50">git</span><span style="color:#96D0FF"> config</span><span style="color:#6CB6FF"> --global</span><span style="color:#96D0FF"> http.https://gitee.com.proxy</span><span style="color:#96D0FF"> ""</span></span></code></pre></figure>
</li>
</ul>
<h2>九、进阶设置（可选）</h2>
<h3>路由模式</h3>
<p>右下角路由下拉框可选择：</p>
<ul>
<li><strong>绕过大陆 (Whitelist)：</strong> 国内网站直连，国外网站走代理（推荐）</li>
<li><strong>全局 (Global)：</strong> 所有流量都走代理</li>
<li><strong>直连 (Direct)：</strong> 所有流量直连，不走代理</li>
</ul>
