<p><strong>前端调用：</strong></p>
<figure data-rehype-pretty-code-figure=""><pre tabindex="0" data-language="typescript" data-theme="github-dark-dimmed"><code data-language="typescript" data-theme="github-dark-dimmed" style="display: grid;"><span data-line=""><span style="color:#6CB6FF">POST</span><span style="color:#F47067"> /</span><span style="color:#ADBAC7">api</span><span style="color:#F47067">/</span><span style="color:#ADBAC7">auth</span><span style="color:#F47067">/</span><span style="color:#ADBAC7">passkey</span><span style="color:#F47067">/</span><span style="color:#ADBAC7">challenge</span></span>

<h2>🔑 关键概念说明</h2>
<h3>1. Challenge（挑战）</h3>
<ul>
<li><strong>作用</strong>：防重放攻击</li>
<li><strong>生成</strong>：服务端生成随机字符串</li>
<li><strong>验证</strong>：确保响应是针对当前请求的</li>
</ul>
<h3>2. User ID（用户标识）</h3>
<ul>
<li><strong>注册时</strong>：服务端生成唯一ID，传入 <code>user.id</code></li>
<li><strong>存储位置</strong>：认证器设备本地（可发现凭证）</li>
<li><strong>登录时</strong>：从 <code>userHandle</code> 中获取</li>
</ul>
<h3>3. Resident Key（可发现凭证）</h3>
<ul>
<li><strong>特点</strong>：用户信息存储在设备本地</li>
<li><strong>优势</strong>：登录时无需输入用户名</li>
<li><strong>设置</strong>：<code>requireResidentKey: true</code></li>
</ul>
<h3>4. AllowCredentials（允许的凭证）</h3>
<ul>
<li><strong>提供时</strong>：限制只能使用指定的凭证</li>
<li><strong>不提供时</strong>：浏览器枚举所有可发现凭证（无用户名登录）</li>
</ul>
<h3>5. Counter（计数器）</h3>
<ul>
<li><strong>作用</strong>：防止重放攻击</li>
<li><strong>规则</strong>：每次使用后必须递增</li>
<li><strong>验证</strong>：服务端检查 counter 是否大于上次的值</li>
</ul>
<h3>6. Signature（签名）</h3>
<ul>
<li><strong>生成</strong>：使用私钥对 <code>challenge + authenticatorData</code> 签名</li>
<li><strong>验证</strong>：使用公钥验证签名，证明拥有私钥</li>
</ul>

<h2>🔒 安全机制</h2>
<h3>1. 防重放攻击</h3>
<ul>
<li><strong>Challenge</strong>：每次请求生成新的随机 challenge</li>
<li><strong>Counter</strong>：每次使用后递增，防止重复使用</li>
</ul>
<h3>2. 域名验证</h3>
<ul>
<li><strong>Origin</strong>：验证请求来源</li>
<li><strong>RP ID</strong>：验证依赖方ID（域名）</li>
</ul>
<h3>3. 用户验证</h3>
<ul>
<li><strong>User Verification</strong>：要求用户验证（指纹/人脸/PIN）</li>
<li><strong>防止</strong>：设备被盗用</li>
</ul>
<h3>4. 签名验证</h3>
<ul>
<li><strong>私钥</strong>：永远不离开设备</li>
<li><strong>公钥</strong>：存储在服务端，用于验证签名</li>
</ul>
