15:T4a0e,<h1>Ollama + Qwen 本地部署指南（Docker + GPU 加速）</h1>
<blockquote>
<p>适用环境：Windows 11 + WSL2 + Docker Desktop + NVIDIA RTX 4060 Ti（16GB）</p>
<p>部署时间：约 10~15 分钟（不含模型下载）</p>
</blockquote>
<h2>一、前置准备</h2>
<h3>1.1 确认已安装</h3>
<table>
<thead>
<tr>
<th>组件</th>
<th>检查命令</th>
<th>说明</th>
</tr>
</thead>
<tbody>
<tr>
<td>Docker Desktop</td>
<td><code>docker --version</code></td>
<td>需开启 WSL2 后端</td>
</tr>
<tr>
<td>WSL2</td>
<td><code>wsl -l -v</code></td>
<td>确保有 Linux 发行版在运行</td>
</tr>
<tr>
<td>NVIDIA 驱动</td>
<td><code>nvidia-smi</code></td>
<td>宿主机需能识别显卡</td>
</tr>
<tr>
<td>NVIDIA Container Toolkit</td>
<td><code>docker run --rm --gpus all nvidia/cuda:12.0-base nvidia-smi</code></td>
<td>让 Docker 容器调用 GPU</td>
</tr>
</tbody>
</table>
<h3>1.2 显存确认</h3>
<figure data-rehype-pretty-code-figure=""><pre tabindex="0" data-language="bash" data-theme="github-dark-dimmed"><code data-language="bash" data-theme="github-dark-dimmed" style="display: grid;"><span data-line=""><span style="color:#F69D50">nvidia-smi</span></span></code></pre></figure>
<p>确认显存容量：</p>
<ul>
<li><strong>8GB 版：</strong> 建议运行 <code>qwen3:8b</code> 或 <code>qwen3.5:9b</code></li>
<li><strong>16GB 版：</strong> 可运行 <code>qwen3:14b</code>、<code>qwen3.5:9b</code>，甚至尝试 <code>qwen3:30b-a3b</code>（MoE）</li>
</ul>
<h2>二、部署 Ollama 服务</h2>
<h3>2.1 拉取官方镜像</h3>
<figure data-rehype-pretty-code-figure=""><pre tabindex="0" data-language="bash" data-theme="github-dark-dimmed"><code data-language="bash" data-theme="github-dark-dimmed" style="display: grid;"><span data-line=""><span style="color:#F69D50">docker</span><span style="color:#96D0FF"> pull</span><span style="color:#96D0FF"> ollama/ollama</span></span></code></pre></figure>
<p>镜像大小约 <strong>8~9GB</strong>。</p>
<h3>2.2 启动容器（GPU 模式）</h3>
<figure data-rehype-pretty-code-figure=""><pre tabindex="0" data-language="bash" data-theme="github-dark-dimmed"><code data-language="bash" data-theme="github-dark-dimmed" style="display: grid;"><span data-line=""><span style="color:#F69D50">docker</span><span style="color:#96D0FF"> run</span><span style="color:#6CB6FF"> -d</span><span style="color:#6CB6FF"> --name</span><span style="color:#96D0FF"> ollama</span><span style="color:#6CB6FF"> --gpus</span><span style="color:#96D0FF"> all</span><span style="color:#6CB6FF"> -p</span><span style="color:#96D0FF"> 11434:11434</span><span style="color:#6CB6FF"> -v</span><span style="color:#96D0FF"> ollama-data:/root/.ollama</span><span style="color:#96D0FF"> ollama/ollama</span></span></code></pre></figure>
<p>参数说明：</p>
<table>
<thead>
<tr>
<th>参数</th>
<th>含义</th>
</tr>
</thead>
<tbody>
<tr>
<td><code>-d</code></td>
<td>后台运行</td>
</tr>
<tr>
<td><code>--name ollama</code></td>
<td>容器名称</td>
</tr>
<tr>
<td><code>--gpus all</code></td>
<td>允许容器使用所有 GPU</td>
</tr>
<tr>
<td><code>-p 11434:11434</code></td>
<td>映射 API 端口</td>
</tr>
<tr>
<td><code>-v ollama-data:/root/.ollama</code></td>
<td>命名卷持久化模型数据</td>
</tr>
</tbody>
</table>
<p><strong>注意：</strong> 如果报错 <code>could not select device driver</code>，说明 NVIDIA Container Toolkit 未安装，需先安装或去掉 <code>--gpus all</code> 用 CPU 模式运行。</p>
<h3>2.3 验证容器状态</h3>
<figure data-rehype-pretty-code-figure=""><pre tabindex="0" data-language="bash" data-theme="github-dark-dimmed"><code data-language="bash" data-theme="github-dark-dimmed" style="display: grid;"><span data-line=""><span style="color:#F69D50">docker</span><span style="color:#96D0FF"> ps</span></span></code></pre></figure>
<p>应看到 <code>ollama</code> 容器在运行。</p>

<h2>五、部署 Open WebUI（可选）</h2>
<p>命令行交互不够方便，可部署网页版界面。</p>
<h3>5.1 启动 Open WebUI 容器</h3>
<figure data-rehype-pretty-code-figure=""><pre tabindex="0" data-language="bash" data-theme="github-dark-dimmed"><code data-language="bash" data-theme="github-dark-dimmed" style="display: grid;"><span data-line=""><span style="color:#F69D50">docker</span><span style="color:#96D0FF"> run</span><span style="color:#6CB6FF"> -d</span><span style="color:#6CB6FF"> -p</span><span style="color:#96D0FF"> 3000:8080</span><span style="color:#6CB6FF"> --add-host=host.docker.internal:host-gateway</span><span style="color:#6CB6FF"> -v</span><span style="color:#96D0FF"> open-webui:/app/backend/data</span><span style="color:#6CB6FF"> --name</span><span style="color:#96D0FF"> open-webui</span><span style="color:#6CB6FF"> --restart</span><span style="color:#96D0FF"> always</span><span style="color:#96D0FF"> ghcr.io/open-webui/open-webui:main</span></span></code></pre></figure>
<p>镜像大小约 <strong>3~4GB</strong>。</p>
<h3>5.2 访问界面</h3>
<p>浏览器打开：</p>
<figure data-rehype-pretty-code-figure=""><pre tabindex="0" data-language="text" data-theme="github-dark-dimmed"><code data-language="text" data-theme="github-dark-dimmed" style="display: grid;"><span data-line=""><span>http://localhost:3000</span></span></code></pre></figure>
<p>首次使用需注册账号，然后即可在网页中选择模型、进行对话、上传文件等。</p>
<h3>5.3 Open WebUI 功能</h3>
<ul>
<li>类似 ChatGPT 的聊天界面</li>
<li>一键切换本地模型</li>
<li>对话历史保存</li>
<li>文件上传与知识库（RAG）</li>
<li>多用户支持</li>
</ul>

<h2>八、常见问题</h2>
<p><strong>Q1：模型下载很慢怎么办？</strong></p>
<ul>
<li>检查网络连接</li>
<li>或配置 Docker 镜像加速器（如阿里云、中科大镜像源）</li>
</ul>
<p><strong>Q2：容器重启后模型不见了？</strong></p>
<ul>
<li>确认启动时使用了 <code>-v ollama-data:/root/.ollama</code> 数据卷挂载</li>
<li>如果没用卷，模型只存在于容器内部，删除容器即丢失</li>
</ul>
<p><strong>Q3：GPU 没生效，模型在 CPU 上跑？</strong></p>
<ul>
<li>宿主机 <code>nvidia-smi</code> 是否正常输出</li>
<li>NVIDIA Container Toolkit 是否安装</li>
<li>Docker Desktop 设置中是否启用了 WSL2 集成</li>
</ul>
<p><strong>Q4：想让局域网其他设备访问？</strong></p>
<ul>
<li>将端口映射改为 <code>-p 0.0.0.0:11434:11434</code></li>
<li>并确保防火墙放行</li>
</ul>
<p><strong>Q5：Qwen3.5 输出很长的 Thinking Process 怎么关？</strong></p>
<ul>
<li>在对话中输入 <code>/set parameter no_think true</code></li>
<li>或重启容器时加环境变量 <code>-e OLLAMA_NO_THINK=true</code></li>
</ul>
