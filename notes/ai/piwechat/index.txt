<h2>三、遇到的问题与解决方案</h2>
<p><strong>问题 1：Pi 进入 Agent 对话模式而非执行命令</strong></p>
<ul>
<li><strong>现象：</strong> 输入 <code>pi gateway</code> 后，系统没有启动网关服务，而是进入了 AI 思考/对话模式，开始搜索文件。</li>
<li><strong>原因：</strong> Pi 的默认行为被设置为 Agent 交互模式，而非命令行工具模式。</li>
<li><strong>解决方案：</strong>
<ul>
<li>通过 <code>Ctrl + C</code> 强制退出对话模式，回到命令行提示符</li>
<li>使用 <code>npx @earendil-works/pi@latest gateway start</code> 强制启动后台服务</li>
</ul>
</li>
</ul>
<p><strong>问题 2：Pi 版本过旧存在连接 Bug</strong></p>
<ul>
<li><strong>现象：</strong> 终端显示黄色警告，提示版本 0.84.2 存在已知问题。</li>
<li><strong>解决方案：</strong> 执行 <code>pi update</code> 将 Pi 从 0.84.2 升级至 0.84.3。</li>
<li><strong>更新结果：</strong>
<ul>
<li>成功升级 <code>@earendil-works/pi-coding-agent</code> 从 0.84.2 到 0.84.3</li>
<li>过程中出现 11 个 deprecated subdependencies 警告，属于 npm/pnpm 常见警告，完全无害，可忽略</li>
</ul>
</li>
</ul>
<p><strong>问题 3：微信已连接但消息处理崩溃</strong></p>
<ul>
<li><strong>现象：</strong> 微信机器人启动成功（显示 <code>Bot started successfully!</code> 和 <code>WeChat connected!</code>），但发送消息后终端疯狂报错：</li>
</ul>
<figure data-rehype-pretty-code-figure=""><pre tabindex="0" data-language="text" data-theme="github-dark-dimmed"><code data-language="text" data-theme="github-dark-dimmed" style="display: grid;"><span data-line=""><span>Extension "&#x3C;runtime>" error: Agent is already processing.</span></span></code></pre></figure>
<ul>
<li><strong>原因：</strong> Pi 的 Agent 默认是单线程处理的，当多条消息同时到达或初始化时触发多次调用，导致并发冲突。</li>
<li><strong>解决方案：</strong> 在消息处理逻辑中添加 <code>isProcessing</code> 标志位（锁机制），确保上一条消息处理完再处理下一条：</li>
</ul>

<span data-line=""><span style="color:#F47067">        return</span><span style="color:#ADBAC7">;</span></span>
<span data-line=""><span style="color:#ADBAC7">    }</span></span>
<span data-line=""><span style="color:#ADBAC7">    isProcessing </span><span style="color:#F47067">=</span><span style="color:#6CB6FF"> true</span><span style="color:#ADBAC7">;</span></span>

<span data-line=""><span style="color:#768390">        // 处理消息逻辑</span></span>

<span data-line=""><span style="color:#ADBAC7">        console.</span><span style="color:#DCBDFB">error</span><span style="color:#ADBAC7">(</span><span style="color:#96D0FF">'处理出错:'</span><span style="color:#ADBAC7">, error);</span></span>

<span data-line=""><span style="color:#ADBAC7">    }</span></span>
<span data-line=""><span style="color:#ADBAC7">});</span></span></code></pre></figure>
